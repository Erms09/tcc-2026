# IndieHub — Front-end React

Front-end acadêmico baseado no TCC "Sistema Web de Catálogos de Jogos Indies".

## Funcionalidades implementadas

- Vitrine de jogos
- Busca por jogo/desenvolvedor
- Filtro por gênero
- Filtro por tipo (2D/3D)
- Página de detalhes do jogo
- Avaliação exibida
- Sistema de comentários em modo demonstração
- Links externos para Steam, GitHub e Discord
- Área de cadastro de desenvolvedor
- Área visual indicando a futura automação de divulgação por IA/Instagram
- Layout responsivo para computador e celular

## Rodar o projeto

Requer Node.js instalado.

```bash
npm install
npm run dev
```

Depois abra o endereço mostrado pelo Vite no terminal.

## Observação importante

Este projeto é o FRONT-END. Os dados estão em `src/data.js` para demonstração.

A integração real com Node.js + MySQL, autenticação, persistência de comentários/cadastros e IA/Instagram deve ser conectada posteriormente ao back-end.
