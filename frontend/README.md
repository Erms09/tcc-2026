# IndieHub — Front-end React

Front-end do TCC "Sistema Web de Catálogos de Jogos Indies".

```bash
npm install
npm run dev
```

## Estrutura
- `src/App.jsx`: estado global (Context + localStorage), rotas e telas
- `src/data.js`: jogos de demonstração
- `src/styles.css`: estilos (tema escuro/claro por variáveis CSS)

Dados, login e comentários são de demonstração (salvos no localStorage).
Back-end (Node.js + MySQL), autenticação real e IA/Instagram serão ligados depois.
